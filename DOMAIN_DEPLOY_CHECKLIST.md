# Настройка https://super-meadow-3240.nadiiahonda34.workers.dev

## Уже настроено в пакете
- основной URL: `https://super-meadow-3240.nadiiahonda34.workers.dev`;
- canonical для главной и служебных страниц;
- `robots.txt` со ссылкой на `https://super-meadow-3240.nadiiahonda34.workers.dev/sitemap.xml`;
- sitemap с абсолютными URL;
- Open Graph URL;
- WebSite JSON-LD;
- production env template.

## После покупки/подключения домена
1. Направить DNS домена на выбранный хостинг.
2. Включить HTTPS и постоянный redirect HTTP → HTTPS.
3. Выбрать единственную основную версию домена (`https://super-meadow-3240.nadiiahonda34.workers.dev`) и перенаправлять альтернативы, включая `www`, на неё.
4. После перехода на динамическую production-версию автоматически генерировать sitemap только из опубликованных рецептов.
5. На каждой странице рецепта выводить canonical и Recipe JSON-LD из фактических данных страницы.
6. Добавить домен в Google Search Console, подтвердить владение и отправить `https://super-meadow-3240.nadiiahonda34.workers.dev/sitemap.xml`.
7. Проверить несколько рецептов в Rich Results Test и URL Inspection.
8. Не индексировать черновики, очередь модерации, личные кабинеты, внутренний поиск и административные страницы.
9. Перед включением аналитики/рекламы заполнить юридические реквизиты и настроить consent в соответствии с фактическими сервисами и применимым законодательством.

## Важно
Этот пакет не может сам изменить DNS, купить домен или подтвердить Search Console: эти действия выполняются в аккаунтах владельца домена/хостинга/Google.
